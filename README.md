# Mapping-Bonneville-Basin-Dust
Contains the custom code for mapping dust from the Bonneville Basin


[![DOI](https://zenodo.org/badge/1398722837.svg)](https://doi.org/10.5281/zenodo.23070517)


Separate README files are provided for the different parts of the code process. Each can be found in the following folders:
*Soil Survey Data* - Source hotspot identification and analysis
*Max Elevation for GSL*
*HYSPLIT*
*Identification and Analysis of Points*

**Note:** This dataset has utilized a variety of data sources, software, and 
This project has used R
Google Earth Engine
Google Cloud Storage
and various nodes at the University of Utah's Center of High Performance Computing
